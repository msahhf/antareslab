# 🚀 AntaresStudio

**AntaresStudio** — modern, güçlü ve geliştirilebilir Python tabanlı bir görsel işleme, kamera kontrol ve 360° çekim çözümüdür.  
Hem masaüstü kullanıcılar hem geliştiriciler için **çalışan EXE build’leri**, **installer’lar** ve **kaynak kod** ile birlikte tam bir üretim hattı sunar.

---

## ✨ Proje Özellikleri

🎯 **All-in-One Desktop Uygulama**  
- PyQt6 tabanlı kullanıcı arayüzü  
- Görüntü yakalama & indirme  
- 360° stüdyo kontrol  
- ESP32/Arduino uyumlu

⚙️ **Esnek Build Sistemi**  
- PyInstaller ile tek tıklık `.exe` üretimi  
- Windows installer (.exe) hazır scriptler  
- VC++ Runtime otomatik kurulum desteği

📦 **Opsiyonel Ek Modüller**  
- Open3D: 3D modelleme & mesh export  
- rembg (CPU/GPU): AI destekli arka plan temizleme

📁 **Temiz Repository**  
- Kaynak kod
- Build scriptleri
- Installer scriptleri
- Yükleme ve kullanım talimatı
